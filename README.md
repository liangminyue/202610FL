# 🩸 输血是否有效预测系统

基于 **CatBoost** 最优模型构建的在线预测 Web 应用，可直接部署到
**Streamlit Community Cloud**，开箱即用。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 单样本预测 | 表单输入临床指标 → 输出预测概率 + 预测结果 + 特征重要性图 + SHAP 单样本归因 |
| 批量预测 | 上传 CSV（可含真实标签）→ 批量预测 → 下载结果，自动计算 AUC 校验 |
| SHAP 可解释性 | 全局：平均绝对 SHAP 条形图 + 蜂群图 + 重要性表；单样本：瀑布图 + 贡献表；特征依赖图 |
| 模型信息 | 展示模型概况、性能指标、输入字段说明与预测流程 |

## 🔒 隐私与安全

- **模型包不含任何真实患者数据**：SHAP 背景样本与内置示例数据均为**合成数据**，
  由训练集各特征的均值 / 标准差随机生成，仅用于演示与可解释性展示，**不可回溯到任何真实病历**。
- **运行时零本地数据依赖**：应用仅需 `model/predict.pkl`（模型权重 + 合成样本），
  不再读取任何原始临床数据文件；批量预测由用户自行上传 CSV，或一键加载内置合成示例。
- **`sample_input.csv` 为合成模板**：仅含字段结构与示例取值，不含真实患者记录。
- **部署建议**：
  - 代码仓库请设为**私有**，或经带鉴权的反向代理发布；
  - 公网 / 局域网部署务必配置访问鉴权，避免未授权访问；
  - `config.toml` 已启用 `enableXsrfProtection` 等安全项，请勿将服务绑定到 `0.0.0.0` 暴露于公网。

## 🚀 快速开始（本地）

### 方式一：一键双击（推荐，Windows）

直接双击本文件夹内的 **`启动本地预测.bat`**，脚本会自动：

1. 定位 Python 解释器（优先使用自带虚拟环境，其次系统 Python）；
2. 检查依赖，缺失时自动 `pip install -r requirements.txt`（失败自动切清华镜像）；
3. 从 8501 起自动选择一个空闲端口；
4. 启动应用并自动打开浏览器。

> 关闭弹出的命令行窗口即可停止服务；结果目录根下也有一份同名脚本。

### 方式二：命令行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 `http://localhost:8501` 即可使用。

## ☁️ 部署到 Streamlit Community Cloud

1. 新建 GitHub 仓库，将本文件夹内**所有文件**（`app.py`、`model/`、`requirements.txt`、`.streamlit/`、`README.md`、`sample_input.csv`）推送到仓库根目录；
2. 打开 [share.streamlit.io](https://share.streamlit.io) 并登录；
3. 点击 **Create app** → 选择仓库 → Main file 填 `app.py` → **Deploy**；
4. 等待自动安装依赖（约 2~3 分钟）即可访问。

> ⚠️ 模型文件 `model/predict.pkl` **必须一起上传**，否则应用无法启动。

## 📊 模型说明

- **算法**：CatBoost
- **性能**：测试集 AUC=0.717；外部验证 AUC=0.701（2 个外部集）
- **决策阈值**：0.6533（约登指数最大化最佳临床截断点）
- **训练样本**：1039 例（训练 727 / 测试 312），目标「是否有效」
- **特征数量**：9 个（由 9 个候选特征经特征筛选保留）
- **可解释性**：内置 SHAP —— 全局（平均绝对 SHAP 条形图、蜂群图、重要性表）、
  单样本（瀑布图 + 各特征贡献表）、特征依赖图

## 🧬 输入字段说明

> 下列字段为**特征筛选后模型实际需要的输入**（原始变量），筛选中被淘汰的变量不再需要填写。

- **分类指标（3 项）**：血型、性别、高血压。二分类保留 0/1 单列，多分类 drop-first 独热编码。
- **连续指标（6 项）**：PLT、RBC、身高、输血量、DBIL、TBIL。

**建模特征（9 个，编码后）**：血型_2.0、高血压、DBIL、输血量、PLT、TBIL、身高、RBC、性别

## 🔄 预测流程

```
原始临床输入（3 个分类 + 6 个连续）→ 分类变量独热编码
→ 从 9 个候选中选取 9 个最终特征 → 缺失值均值填充
→ Z-score 标准化 → CatBoost 输出概率 → 与阈值 0.6533 比较 → 输出结果
```

## 🛠 重新打包模型（可选）

训练出新模型后，可修改 `pack_model.py` 中的路径配置，然后执行：

```bash
python pack_model.py
```

即可重新生成 `model/predict.pkl`。
